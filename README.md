# proyecto-final-pagina-web
Nombre del proyecto: Paradise Nursery

Descripción: Paradise Nursery es una tienda virtual dedicada a la venta de plantas para el hogar y la oficina. La página permite a los usuarios conocer diferentes tipos de plantas, consultar sus precios y agregarlas a un carrito de compras.

Objetivo: Crear una página web funcional y fácil de usar que permita a los clientes explorar y comprar plantas de manera sencilla.

React

JavaScript

HTML

CSS

Redux Toolkit

Página de inicio

Catálogo de plantas

Información sobre la empresa

Carrito de compras

Agregar y eliminar productos

Actualizar cantidades

Cálculo del total de la compra

🌱 Paradise Nursery

Nombre de la empresa: Paradise Nursery Tipo de empresa: Tienda y comercio de plantas Eslogan: Lleva la naturaleza a tu hogar.

¿Quiénes somos? Paradise Nursery es una tienda dedicada a la comercialización de plantas para interiores y exteriores. Ofrecemos diferentes especies de plantas ornamentales, suculentas, cactus y plantas ideales para decorar hogares, oficinas y otros espacios.

Nuestro objetivo es facilitar a nuestros clientes la compra de plantas y brindarles información básica para que puedan elegir y cuidar adecuadamente cada especie.

Misión

Ofrecer plantas de buena calidad y una experiencia de compra sencilla, ayudando a nuestros clientes a encontrar las plantas ideales para sus espacios y promoviendo el cuidado y respeto por la naturaleza.

Visión

Ser una tienda de plantas reconocida por la variedad de sus productos, la calidad de su servicio y el compromiso con el cuidado del medio ambiente.

Valores

Responsabilidad: Cuidamos nuestros productos y cumplimos con nuestros clientes.

Calidad: Buscamos ofrecer plantas en buenas condiciones.

Respeto: Promovemos el respeto por la naturaleza.

Compromiso: Trabajamos para brindar una buena experiencia de compra.

Amor por la naturaleza: Queremos acercar los espacios verdes a la vida cotidiana.
